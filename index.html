Make it feel like home.

This is a flexible starting model of the single room from Project 3, not a surveyed architectural plan.

  1. Tap any furniture in the scene or list to select it.
  2. Drag furniture to move it. In the Edit panel, use the rotate buttons or angle slider.
  3. Switch between 2D and 3D. In 3D, drag empty space to orbit. Pinch to zoom; two fingers pan. In 2D, drag empty space to pan.
  4. Your changes save automatically in this browser. Use Share layout to send a link with the arrangement, or Export for a backup.
  5. Adjust the room in Edit & room → Room measurements. The little upper-left corner and right-hand step are estimates. Door widths and hinge sides can be adjusted in Edit & room → Doors.
